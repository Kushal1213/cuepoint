Privacy

Your screen is context, not a collection.

Cuepoint has no account system and no database of your work. This page explains what stays local, what a request sends, and when temporary data expires.

Last updated October 23, 2026

No Cuepoint server

The app's private service runs on your computer and does not archive screenshots, questions, clipboard text, or answers.

Keys stay encrypted

Connected keys and tokens are protected by your Windows account with DPAPI.

Diagnostics are optional

They start off and never include screen content, questions, files, answers, keys, or tokens.

Stored on this computer

Settings

Voice, model, permission, and diagnostics choices.

Keys and tokens

Gemini, OpenAI, Tavily, and GitHub credentials encrypted with Windows DPAPI.

Task History

The latest 50 Act runs: request, plan, steps, typed text, and outcome. It stores no screenshots.

Speech model

The optional Parakeet model, about 670 MB. Hugging Face sees standard connection data such as your IP during the download.

Local voice audio

Held only while it is transcribed on-device, then discarded. The microphone is active only while you hold the voice shortcut.

Remove local data by deleting %APPDATA%\io.github.kushal1213.cuepoint and %LOCALAPPDATA%\io.github.kushal1213.cuepoint.

Sent when you make a request

Cuepoint's local service sends each request directly to the model selected in Settings under your key. Cuepoint does not operate an intermediary server.

Screenshot and question

Sent by the local service to Google Gemini or OpenAI with your key. Act sends a fresh screenshot before each screen-based step.

Clipboard text

Included only with Act tasks so the task can use it.

Browser page details

Names of visible links, buttons, and fields, plus the page address, are sent for browser steps.

Web search

Search terms go to Tavily only when you connect Tavily and the task needs current web information.

GitHub

Read-only requests use your connected token. Cuepoint does not write to GitHub.

Update check

The app asks GitHub for the latest release number when it starts.

If you choose OpenAI voice transcription, audio goes directly from your computer to OpenAI under your key. It does not pass through the Cuepoint backend.

Temporary local processing

Requests

Screenshots, questions, and credentials remain in local memory only while the request runs.

Act results

The answer and task plan wait in local memory for up to five minutes for the app to collect them.

Conversation context

A short session history remains in local memory for follow-up questions and expires after inactivity or when Cuepoint exits.

The application does not write request content to a database, and its task queue does not persist that content to disk.

Services you may reach

Google or OpenAI processes model requests, depending on your selection. Tavily processes web searches when connected. GitHub serves update checks and read-only repository requests when connected. Hugging Face serves the optional speech-model download. Their own terms and privacy policies apply.

Optional diagnostics

Cuepoint asks once and leaves diagnostics off unless you enable them. When on, PostHog receives feature events, outcome states, step counts, the Cuepoint version, the Windows build, and a random installation ID. IP and location capture are disabled.

Diagnostics never include screenshots, questions, task text, clipboard contents, file names or contents, answers, keys, or tokens.

This website

The public site uses PostHog for lightweight page-view and referrer counts. It does not use advertising cookies or build a Cuepoint user account. Browser privacy signals and common bot traffic are respected by the site script.

Your controls

  • Turn diagnostics off in Settings.
  • Clear Task History from its window.
  • Disconnect any model or service key in Settings.
  • Delete the local Cuepoint folders to remove all app data.
  • Inspect or build the complete AGPLv3 source.
