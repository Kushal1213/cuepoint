Setup

From install to first answer.

Connect one model key, choose an action policy, and use Cuepoint from any Windows app.

01

Install and open

  1. Download the latest Windows installer and run it.
  2. Open Cuepoint from the Start menu. It stays available in the system tray.
  3. Press Ctrl + Alt + Space from any app.

Cuepoint asks once about anonymous diagnostics. They are off by default, and skipping does not change the product.

02

Connect a model

Cuepoint supports Gemini and OpenAI across answers, guides, actions, screen reading, and connected tools. Open Settings, paste one API key, then choose any screenshot-capable model available to that key.

Gemini

Create a key in Google AI Studio, then connect it under Gemini API key.

OpenAI

Create a key on the OpenAI platform, then connect it under OpenAI API key.

Keys are stored with Windows encryption (DPAPI). Model use is billed by the provider attached to your key.

03

Choose the kind of help

Ask

Get a focused answer

Type a question with no prefix. Cuepoint answers from the current screen and can point to the relevant detail.

guide:

Walk through what is visible

Cuepoint breaks the explanation into narrated steps and draws points, boxes, or arrows on the screen.

act:

Complete a task

Cuepoint can type, open apps, search the web, read connected sources, and work through a browser flow under your action policy.

The earlier explain: and agent: prefixes remain as compatibility aliases.

04

Set the action boundary

Action permission in Settings determines what happens after Cuepoint proposes a task.

Review each actionDefault

See the proposal or plan first. Press Enter to allow it or Esc to cancel.

Run automatically

Start a plan without the review screen. Each step remains visible, and Esc stops the task.

Off

Keep Ask and Guide. Disable typing, clicking, and app launches.

Task History keeps the latest 50 task records on this computer. It includes the request, plan, steps, typed text, and outcome, but no screenshots.

05

Choose how voice works

Hold Ctrl + Win, speak, then release. Start with “guide” or “act” to switch modes by voice.

On-device

Downloads the Parakeet speech model once, about 670 MB. Audio is transcribed locally, never uploaded, and discarded after transcription.

OpenAI

Sends audio directly to OpenAI under your key for transcription. It does not pass through the Cuepoint backend.

Speak answers uses a local Windows voice to read responses. Use Test in Settings to preview the selected voice.

06

Add only the connections you need

Web search

Connect a Tavily key when Act needs current information. Skip it for screen-only tasks.

GitHub

Connect a fine-grained token with read-only access to Contents, Issues, and Pull requests. Cuepoint never writes to GitHub.

Browser tasks

Install Node.js before the first browser task. Cuepoint then downloads a browser component once, about 300 MB, and opens a separate unsigned-in browser for each run.

Browser actions target named buttons, links, and fields instead of guessing screen coordinates. New-tab links and some native dropdowns remain limited; Cuepoint stops when it cannot make safe progress.
